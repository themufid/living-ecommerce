# Atelier Living

Toko furnitur fiktif untuk presentasi Paket Toko Online Premium. Situs ini berjalan tanpa database: katalog, akun, keranjang, dan pesanan tersimpan di peramban.

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://127.0.0.1:3000

Untuk produksi:

```bash
npm run build
npm start
```
